# Locally Flexible Preferential Attachment (LFPA)

This repository accompanies the following paper:

Tingyu Zhao, Balázs Maga, Pierfrancesco Dionigi, Gergely Ódor, Kyle Soni, Anastasiya Salova, Bingjie Hao, Miklós Abért, and István A. Kovács. “[Preferential attachment with local flexibility](https://doi.org/10.1103/9y9m-q7qj).” *Physical Review Letters* **(2026)**.


---

## Contents
- **`model_CR.py`** – Efficient implementation for simulating constant redirection (CR) networks, parameterized by $(\alpha, r)$
- **`model_LFPA.py`** – Efficient implementation for simulating LFPA networks, parameterized by $\alpha$
- **`Generate.ipynb`** – Demonstration notebook to generate simulation samples
